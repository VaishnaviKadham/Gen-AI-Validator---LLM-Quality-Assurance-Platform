# Gen-AI-Validator---LLM-Quality-Assurance-Platform
My project brings traditional QA principles to GenAI.
I design test cases in the form of prompts with expected results, run them through the AI model, compare actual vs expected output, detect hallucinations like defects, check consistency like stability testing, score outputs for quality, store results in Azure SQL, and create dashboards to analyze accuracy trends.
Essentially, I treat the AI model as a software system and apply QA processes to ensure its reliability.”
